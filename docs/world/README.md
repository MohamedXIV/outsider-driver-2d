# Charter-port city integration

Source: MohamedXIV/outsider-driver, Draft PR #84, branch `docs/city-world-foundation-v0`, commit `59d2a0004363c3d1a37379f22cba93276d3f7d01`. The five files in `reference/` are preserved source documents and an editable SVG. Their references to old runtime code, 3D, Babylon, Pixi, and approval gates are historical, not instructions for this project.

Confirmed for this integration: self-governing charter-port city-state under external trade/treaty constraints; excluded human taxi driver; inhabited and functioning poor Outer Margin; wheeled transport; supported elevated infrastructure; tactile alien retro-futurism.

Adapted working geography: Docks, Worker Belt, Old Junction, Civic Core, Upper Terraces, Outer Margin around the western cargo basin. Lantern Row, Patchworks garage and The Cut are useful provisional neighborhood names. Actual road junctions and metric centerlines are authored in `SandboxCityData`, independent of district identity. The player starts at Patchworks. Old stop IDs `market`, `depot`, `clinic`, `shelter` now identify real locations within districts, not entire districts.

Everything is native Godot 2D. Exterior presence uses projected polygons, curves, vehicles and camera; contextual service/dialogue panels are anchored to actual locations and the same world. No old runtime was copied. Exact institutions, constitution, ban history, final alien names, city population and final art remain tentative.
